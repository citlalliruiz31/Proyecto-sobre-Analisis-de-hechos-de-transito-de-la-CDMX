# Diccionario de metadatos

Este repositorio incorpora la documentación necesaria para describir las principales fuentes del proyecto de análisis de hechos de tránsito en la Ciudad de México.

## Documentos disponibles
- [Diccionario C5](./Diccionario_o_metadatos/Diccionario_C5.md)
- [Diccionario SSC](./Diccionario_o_metadatos/Diccionario_SSC.MD)
- [Diccionario INEGI ATUS](./Diccionario_o_metadatos/Diccionario_INEGI_ATUS.md)
- [Diccionario Kaggle](./Diccionario_o_metadatos/Diccionario_Kaggle.md)

## Propósito
Los diccionarios tienen como objetivo estandarizar los nombres, significados y tipos de dato esperados para cada fuente, con el fin de facilitar el análisis comparativo entre bases de datos con estructuras distintas.
