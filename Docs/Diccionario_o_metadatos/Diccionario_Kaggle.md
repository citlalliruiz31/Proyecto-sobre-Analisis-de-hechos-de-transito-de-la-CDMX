Diccionario de datos INEGI \- ATUS

La fuente de INEGI corresponde a la Estadística de Accidentes de Tránsito Terrestre en Zonas Urbanas y Suburbanas (ATUS).

A diferencia de las otras fuentes, INEGI cuenta con una documentación de metadatos mucho más estructurada. Para la edición 2024, el diccionario oficial registra 46 variables y las organiza en siete grupos

**METADATOS** 

| ELEMENTO   | DESCRIPCIÓN |
| ----- | ----- |
| Institución  | Institución Nacional de Estadística y Geografía (INEGI) |
| Operacion estadistica  | Estadística de Accidentes de Tránsito Terrestre en Zonas Urbanas y Suburbanas  |
| Nombre corto  | ATUS |
| Cobertura geográfica  | Nacional |
| Unidad de observación  | Accidente de tránsito terrestre  |
| Número de variables  | 46 |
| Información temporal  | Fecha y hora del accidente  |
| Información geográfica  | Ubicación del accidente  |
| Informacion de vehiculos  | Vehículos de personas involucradas  |
| Información de víctimas  | Víctimas muertas y heridas  |
| Información causal  | Tipo y causa del accidente  |
| Fuente de informacion  | Registros administrativos de las autoridades correspondientes  |

 

INEGI explica que ATUS se construye con registros de dependencias de seguridad pública y vialidad estatal/municipal; para la Ciudad de México se consideran registros de Agencias del Ministerio Público o Juzgados Cívicos

**DICCIONARIO POR GRUPOS DE VARIABLES** 

| GRUPO  | QUÉ INFORMACIÓN CONTIENE  | USO EN EL PROYECTO   |
| :---- | :---- | :---- |
| Ubicación del accidente  | Información sobre la entidad y ubicación donde ocurrió  | Analizar distribución geográfica  |
| Fecha y hora del accidente  | Momento en que ocurrió el accidente  | Analizar días, meses y horarios  |
| Datos del conductor presunto responsable  | Información relacionada con el conductor señalado  | Analizar características de los conductores  |
| Vehículos de personas involucradas  | Información de los vehículos participantes  | Comparar tipos de vehículos  |
| Tipo y causa del accidente  | Clasificación y causa del accidente  | Identificar patrones y posibles factores  |
| Víctimas muertas  | Información relacionada con personas fallecidas  | Medir consecuencias graves  |
| Víctimas heridas  | Información relacionada con personas lesionadas  | Medir afectaciones  |

Estos son los siete grupos que aparecen en el diccionario oficial de INEG

**Variables principales de ATUS** 

| Variable  | Que permite analizar  |
| :---- | :---- |
| Entidad federativa  | Ubicar el accidente por entidad  |
| Fecha  | Analizar evolución temporal  |
| Hora  | Detectar horarios con mayor incidencia  |
| Tipo de accidente  | Comparar tipos de accidentes  |
| Causa del accidente  | Identificar causas registradas  |
| Vehículo  | Analizar vehículos involucrados  |
| Conductor  | Analizar características del presunto responsable  |
| Víctimas muertas  | Medir fallecimientos  |
| Víctimas heridas  | Medir lesiones  |

**NOTA:** ***El diccionario oficial de ATUS confirma que el conjunto tiene 46 variables y que están distribuidas en esos grupos temáticos***
